# Frozen fixtures

The six JSON files here were generated by the TypeScript implementation (`test/golden/make-vectors.ts`, removed on 2026-11-27, recoverable from git history) with throwaway self-signed TEST keys.

They are frozen: never regenerate or hand-edit them.

- `xades-rsa.json`, `xades-ec.json`, `xades-awkward-issuer.json`, `xades-organization-identifier.json` pin the XAdES signer; the RSA signature must stay byte-identical.
- `keys.json` pins the key reader.
- `formats.json` pins the on-disk and display formats the owner's existing data uses: index lines, `state.json`, the report, notifications, the snapshot and amounts.
